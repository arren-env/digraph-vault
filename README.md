# Digraph demo vault

Public assets for the [Digraph](https://marketplace.visualstudio.com/items?itemName=arren.digraph) VS Code extension.

- `media/` holds the images shown in the extension's Marketplace README. Keep these paths stable: the published README loads them from this repo.
- `demo-vault/` is a sample Obsidian-style vault of 110 linked notes. Open the folder in VS Code and run **Digraph: Open Graph View** to try the extension.
